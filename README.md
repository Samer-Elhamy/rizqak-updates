# مستودع تحديثات نظام رزقك (Rizqak Updates Distribution)

مستودع عام رسمي مخصص حصرياً لنشر بيانات التحديثات الموقعة رقمياً (`latest.json`) والحزم البرمجية لنظام **رزقك (Rizqak POS)**.

## السياسات والضوابط الأمنية
1. **تحديثات التطبيق فقط (App-Only Updates):**
   - لا يحتوي هذا المستودع على أي قواعد بيانات أو بيانات تجريبية أو بيانات عملاء.
   - لا يحتوي المستودع على أي مفاتيح خاصة أو كلمات مرور.
2. **التوقيع الرقمي الصارم (Cryptographic Signatures):**
   - كافة الحزم والتحديثات موثقة وموقعة باستخدام زوج مفاتيح Ed25519 المعتمد لنظام رزقك.
   - يتحقق النظام تلقائياً من صحة التوقيع عبر المفتاح العام المدمج قبل تثبيت أي تحديث.
3. **قنوات التوزيع (Release Channels):**
   - قناة المعاينة والتجربة (`demo`)
   - القناة المستقرة (`stable`)
